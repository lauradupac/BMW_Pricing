# BMW Pricing Analysis

**Overview:**

This mini coding project utilises Machine Learning in the form of a Neural Network to investigate the factors associated with BMW car prices. The coding (and notes alongside it) explores the dataset, preprocesses the variables, and applies predicted modelling to estimate car prices.

**Dataset:**

The BMW Used Car Listing dataset has been taken from Kaggle. It is available at: <https://www.kaggle.com/datasets/mysarahmadbhat/bmw-used-car-listing>.

It contains information on used BMW cars including the registration year, price, transmission, mileage, fuel type, road tax, miles per gallon, and engine size.

Reference:
bhat (2021). *BMW used car listing*. [online] kaggledatasets. Available at: https://www.kaggle.com/datasets/mysarahmadbhat/bmw-used-car-listing.

**Methods:**

- Data cleaning and preprocessing
- EDA
- Feature engineering
- Neural network model
- Model evaluation
